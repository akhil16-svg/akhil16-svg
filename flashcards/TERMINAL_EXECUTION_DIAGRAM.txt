╔════════════════════════════════════════════════════════════════════════════╗
║                         WHAT'S HAPPENING?                                  ║
╚════════════════════════════════════════════════════════════════════════════╝

    Browser (localhost:3000)
         │
         │ User clicks "Add Card"
         │
         ▼
    React Frontend
         │
         │ fetch('http://localhost:5000/api/cards', {...})
         │
         ▼
    Flask Backend (localhost:5000)
         │
         │ Process request
         │
         ▼
    SQLite Database (flashcards.db)
         │
         │ Save data
         │
         ▼
    Response back to Frontend
         │
         │ JSON data
         │
         ▼
    Browser updates UI


╔════════════════════════════════════════════════════════════════════════════╗
║                    COMMON MISTAKES TO AVOID                                ║
╚════════════════════════════════════════════════════════════════════════════╝

❌ MISTAKE 1: Starting frontend before backend
   → Frontend can't connect, shows errors

❌ MISTAKE 2: Using only ONE terminal
   → Second server won't start, app incomplete

❌ MISTAKE 3: Closing terminal after starting
   → Server stops, app breaks immediately

❌ MISTAKE 4: Not activating virtual environment
   → Python can't find Flask, error occurs

❌ MISTAKE 5: Wrong directory
   → Commands fail, files not found


╔════════════════════════════════════════════════════════════════════════════╗
║                      QUICK TROUBLESHOOTING                                 ║
╚════════════════════════════════════════════════════════════════════════════╝

🔧 Problem: "Address already in use"
   Solution: kill -9 $(lsof -ti:5000)

🔧 Problem: "Connection refused"
   Solution: Backend not running - start it!

🔧 Problem: "Module not found"
   Solution: Activate venv and install requirements

🔧 Problem: Blank page
   Solution: Check browser console, verify backend running
